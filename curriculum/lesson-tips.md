# Lesson tips — DRAFT (LDTKB-068, proposed)

Short tip shown under each lesson's phrase, with the 🔊 Listen and 📖 More buttons. Week 1: one line. Weeks 2–4: up to two lines. `{phrase}` is replaced with the learner's own phrase (with their krap/ka ending).

**Status:** draft — needs Joule's review and a native-speaker check before locking. Code mirror: `src/lib/curriculum/lessonTips.ts`.

## Lesson 8

```
Directions for taxis and motorbike rides.

```

## Lesson 9

```
Handy when your phone is dead — and an easy chat opener.

```

## Lesson 10

```
Three time words you'll hear every day.

```

## Lesson 11

```
Small talk that always lands in Thailand.
mâak = very — put it after almost any describing word.
```

## Lesson 12

```
For clothes shopping when nothing fits.
Swap yài (big) for lék (small) to ask for smaller.
```

## Lesson 13

```
Your café order: ao (want, from Lesson 3) + what + how many.
gâew = glass.
```

## Lesson 14

```
A warm goodbye between friends.

```

## Lesson 15

```

```

## Lesson 16

```
Family words for small talk.
phîi-nórng covers brothers and sisters, older and younger.
```

## Lesson 17

```
Swap duu-nǎng (watch movies) for anything you enjoy.
chôrp = like.
```

## Lesson 18

## Lesson 19
