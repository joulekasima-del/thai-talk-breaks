## Notes
- Every phrase here has already been reviewed and approved by Joule (native Thai speaker), 19 August 2026 — see LOCKED_DECISIONS.md and individual lesson files in curriculum/pilot/.
- **"Sounded out" column:** a syllable-by-syllable Thai-script reading aid (e.g. สวัสดี → สะ-หวัด-ดี), separate from both the formal spelling and the Latin Karaoke system used in the lesson files. This is a draft, and less reliable than the tone marks — syllable respellings depend on knowing exactly which consonant clusters simplify in speech, which I'm not fully confident about. Please check these more carefully than the rest.
- Listen to each generated clip critically before accepting it — vendor tone-accuracy claims are marketing copy, not guarantees. Your ear is the actual quality check.
- Use the same male voice and same female voice consistently across all 22 clips — switching voices mid-curriculum would feel jarring to a learner.
- File naming suggestion once downloaded: `lesson01_male.mp3`, `lesson01_female.mp3`, `lesson02_1.mp3` ... `lesson02_10.mp3`, etc. — matches the lesson file structure already in curriculum/pilot/.
